==> Caveats
==> canopy
Semantic search uses a local bge-m3 ONNX model (~2.3GB). Download it once:
  canopy model pull
Keyword search works without it. If the ONNX Runtime library is not found
automatically (e.g. Linuxbrew or a non-standard prefix), point canopy at it:
  export CANOPY_ONNXRUNTIME_DIR="/opt/homebrew/opt/onnxruntime/lib"

To run the web UI as a background service (http://localhost:8737):
  brew services start canopy
It serves the wiki named by default_wiki. Adopt your wiki first:
  canopy init --wiki /path/to/wiki
If a default already exists, edit default_wiki in your canopy config
while preserving its other settings (the default path is ~/.config/canopy/config.toml).

To restart neutrospec/tap/canopy after an upgrade:
  brew services restart neutrospec/tap/canopy
Or, if you don't want/need a background service you can just run:
  HOMEBREW_PREFIX="/opt/homebrew" /opt/homebrew/opt/canopy/bin/canopy serve
